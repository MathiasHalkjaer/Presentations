# Advanced Agent Skills for Power BI

**Session page:** https://mathiashalkjaer.github.io/Presentations/advanced-agent-skills-for-power-bi/
**Slides:** https://mathiashalkjaer.github.io/Presentations/advanced-agent-skills-for-power-bi/slides/
**Field guide:** [web](https://mathiashalkjaer.github.io/Presentations/advanced-agent-skills-for-power-bi/guide/) · [PDF](guide/advanced-agent-skills-field-guide.pdf)
**Demo project:** https://github.com/MathiasHalkjaer/agent-skills-pbi-demo

Agent Skills look simple: a folder with a SKILL.md. This session goes beneath the surface,
with one Power BI model and one skill that grows piece by piece:

1. **Description:** how a skill is found, and why one line decides whether it loads.
2. **References:** long rules that cost nothing until they're needed.
3. **Scripts:** exact checks the model shouldn't improvise.
4. **Hooks:** rules the harness enforces, every time.
5. **Sub-agents:** dependent work in one place, independent work in parallel.
6. **Learning loop:** a skill that proposes what it was missing, and you decide.
